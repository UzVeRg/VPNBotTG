# VPNBotTG
Репозиторий личного бота для VPN-сервиса

## Временная проверка оплаты и активации

В `.env` задайте `TEST_TELEGRAM_IDS=123456789` (несколько ID через запятую)
и перезапустите бот. По умолчанию список пуст: кнопки скрыты, callbacks запрещены.
Тестировщик может работать только со своими заказами в личном чате.

1. Откройте покупку, выберите тариф и создайте заказ.
2. Нажмите «⚡ Тест: активировать» до оплаты: бот должен попросить отметить оплату.
3. Нажмите «🧪 Тест: отметить оплату»: существующий `Database::mark_payment_paid()`
   переводит платёж и заказ в `paid`, без обращения к платёжному провайдеру.
4. Нажмите «⚡ Тест: активировать»: `ActivationService::activate_order()` создаёт
   или продлевает настоящую подписку в Remnawave. Проверьте статус и ссылку в меню.
5. Повторите обе кнопки: бот должен сообщить об уже проведённой оплате/активации.
6. Очистите `TEST_TELEGRAM_IDS` и перезапустите бот: старые кнопки также перестанут работать.

Используйте тестовую БД и тестовый Remnawave. Платёжные деньги не списываются,
но состояние БД и подписка изменяются реально. Одновременные тестовые действия
блокируются в одном процессе; для ручной проверки запускайте один экземпляр бота.
